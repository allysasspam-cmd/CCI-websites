CCI WEBSITE
============

To view:
1. Download and unzip CCI-Website.zip.
2. Open the folder.
3. Double-click index.html.
4. The website will open in your browser.

To add articles:
Open articles.js and add another object to the articles array.
Each article can have a title, category, date, author, excerpt and HTML content.

IMPORTANT:
- Replace cci@example.com with CCI's real email.
- Replace placeholder impact numbers with verified CCI figures.
- Replace the placeholder CCI image blocks with real photos when ready.
